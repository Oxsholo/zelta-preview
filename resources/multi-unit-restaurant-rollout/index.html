Opening Many Restaurant Locations with One Architect

Zelta Design · 5 min read · Updated October 11, 2026 · Reviewed by Erik Liepins, RA

The short answer

A multi-unit rollout goes faster with one architect because the brand prototype, drawing standards and permit tracking stay the same from store to store, while each site still gets its own survey, code review and permit path. The prototype is the starting point; every location is still its own building, landlord and jurisdiction.

If you are opening many restaurants, one architect for all of them saves time in the places that repeat: the brand prototype, the drawing standards, the engineering approach and the way permits are tracked. Each store still needs its own survey, its own code review and its own permit filing, because no two sites are the same building. Most of our clients run 20 or more locations, and the rollouts that go smoothly treat the prototype as a starting point, never a finished drawing.

Here is how we run a multi-unit program and where rollouts usually lose time.

Start with the list, not the first store

The best first step is a rough list of every site you are considering, even if half of them will fall away. For each one we look at what the store needs, what could slow its permit, and what a realistic schedule looks like. Doing this as a batch shows patterns early: which towns need a zoning or site plan step, which landlords have tenant criteria, which states have a separate state health or fire review.

For remodel programs this matters even more. We may already know some of your stores, and in some cases still have drawings on file from earlier work.

Lock the prototype version

Brands revise their prototypes, and rollouts can span more than one release. Our production rule is simple: each set uses the agreed brand version, and a newer release does not automatically replace a set that is already in progress. Switching versions mid-project is a decision you make with the brand, not something that drifts in through a drawing update.

The prototype then sets a lot of the technical answers. On Taco Bell projects, for example, the exhaust hood and fans follow the prototype specification on the roof. Settled answers like these are a large part of what one architect carries from store to store. Our guide to how franchise brand approvals work covers the review stages each version passes through.

Every site still gets surveyed

A prototype assumes an ideal box. Your real spaces have columns, soffits, old panels, rooftop units and a previous tenant’s leftovers. Each of our projects starts with a site visit: every room measured, photos of every wall and the equipment line, a 3D scan you can walk through online, and the electrical panels, plumbing and rooftop units noted. Anything that could affect the permit is flagged on the spot. Our survey guide explains what that visit captures.

When we adapt the prototype, the inherited information gets replaced with confirmed facts for that site: the address, the equipment data, the notes. Copying sets quickly invites leftover details from the last store, so every set is checked for them before it goes out.

Local code beats the prototype

Brand layouts are written for the brand, not for each county. Drive-thru stacking, the number of cars the lane must hold, is a common example: counties and towns set their own counts, and a corporate site layout may need redrawing to meet them. Our guide to drive-thru design covers that review.

Similar gaps show up in zoning (one New Jersey town allowed only one primary building sign, so the proposed signage package needed a variance), in grease interceptor rules set by local sewer authorities, and in historic districts that review storefront changes. A multi-unit architect earns their fee by catching these before the brand approves a layout that the town will not.

Brand review runs alongside

Franchise brands review drawings at set points, and their comments come back on individual sheets, down to details like where a freezer door sits on the kitchen plan. Those revisions need to land before the sealed set goes to the town, or you end up filing twice. On a rollout we keep brand review and permit preparation on the same calendar so that one does not quietly hold up the other.

One permit board for every store

The part of a rollout that most often falls through the cracks is the paperwork between stores. We keep a single permit board covering every filing on every project: building, health, zoning, fire and the rest, each with its status, the next action and whose turn it is. When a filing goes quiet, it shows up as overdue rather than being forgotten.

Many filings wait on owner information, and some agencies close applications that sit incomplete too long. The fix is to assign each item to a person with a date, per store, at kickoff:

Settle repeat questions once

Some questions only need answering once per state or per landlord: whether a state agency runs its own plan review, what a landlord’s tenant criteria require, which forms a state fire marshal wants. Learn them on the first store and reuse the answer, but only as far as it goes. A written answer from an agency covers the sites and scope it names; confirm that it applies to each new location before relying on it.

Crossing state lines

A rollout that crosses state lines needs an architect licensed in every state where a drawing needs a seal. We are licensed in 25 jurisdictions today and work nationwide outside California, Alaska and Hawaii. When a client brings a project to a state where we are not yet licensed, we get licensed there before any drawing needs a seal. Our guide to when you need an architect explains how state licensing works. Our Dave’s Hot Chicken work shows what one team across several states looks like: storefronts in Brooklyn and White Plains, and freestanding drive-thru buildings in Shelby, North Carolina and Sumter, South Carolina, all from one office.

Questions

Common Questions

Can one architect handle restaurant locations in several states?

Yes, as long as the architect is licensed in each state where a drawing needs a seal. Zelta Design is licensed in 25 jurisdictions, works nationwide outside California, Alaska and Hawaii, and gets licensed in a new state when a client's project needs it, before any drawing needs a seal.

If the prototype is already designed, why does each store need new drawings?

Because the prototype assumes an ideal site. Each real location has its own dimensions, utilities, landlord rules and local code requirements, and the permit set has to show that specific building, sealed by a design professional licensed in that state.

What happens when the brand releases a new prototype in the middle of a rollout?

Stores already in progress normally stay on the version that was agreed when they started. A newer release does not automatically replace a set that is underway; switching is a deliberate decision with the brand.

What slows down a multi-unit rollout the most?

Missing owner information at filing time. Applications often wait on signatures, a named general contractor, the construction value, the menu or landlord authorization, so we ask for those per store up front.
